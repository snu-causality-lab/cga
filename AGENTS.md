# Repository Guidelines

The README defines the supported operations. The Python package is under `python/src/causal_graph_algorithms/`, tests are under `tests/python/`, and original-paper examples are under `tests/fixtures/papers/`.

Use the test command in the README. Add a focused failing regression before changing an implementation. For graph algorithms, compare against an independent definition-level implementation or small-graph enumeration. Preserve source citations and the mathematical interpretation of each checked result.
